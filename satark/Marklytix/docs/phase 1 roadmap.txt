DB Scanner Core Engine
New File: sarthi_chatbot/db_scanner/scanner.py
This is the heart of the product. The scanner must:
•Connect to any database using user-provided credentials (server, db, user, password, driver)
•Enumerate all schemas/tables (INFORMATION_SCHEMA.TABLES, INFORMATION_SCHEMA.COLUMNS)
•Read sample data (TOP 5 rows) per table for context
•Extract semantic metadata per table: table name → inferred domain, column names + data types, foreign key relationships, approximate row count, index information

LLM-Powered Category & Subcategory Generator
New File: sarthi_chatbot/db_scanner/category_generator.py
After scanning all tables, use an LLM to group them into categories and subcategories intelligently.
Strategy
•Send batches of 10-15 table names + columns + sample data to LLM
•LLM returns: category, subcategory, keywords, description
•Merge/deduplicate across batches
•Store in Chatbot_Sa_Categories and Chatbot_Sa_Subcategories tables
LLM Prompt for Classification
You are a database domain expert. Group these SQL Server tables into
logical business categories and subcategories.
 
Rules:
- Identify 3-8 top-level CATEGORIES (e.g., Collections, Hierarchy, Staff Management)
- Within each category, create 2-5 SUBCATEGORIES (more specific groupings)
- For each subcategory, provide 15-20 keywords a user might say
- For each subcategory, identify which tables belong to it
 
Return JSON: { categories: [ { name, description, keywords,
  subcategories: [ { name, description, keywords, tables } ] } ] }

Specialized Prompt Auto-Generator
New File: sarthi_chatbot/db_scanner/prompt_generator.py
For each subcategory identified, auto-generate:
•A system prompt for the query LLM (with table schemas, business context)
•3-5 example SQL query pairs (NL question → SQL) to seed the few-shot store
•Business rules extracted from column names (e.g., DPD → "Days Past Due")
PromptGenerator class responsibilities
•generate_subcategory_prompt(subcategory, tables, schema_info, sample_data) → complete T-SQL generator system prompt
•generate_sql_examples(subcategory, tables, schema_info) → list of {question, sql} pairs to seed sarthi_sql_examples
•extract_business_glossary(columns) → expands abbreviations (DPD → Days Past Due, NPA → Non Performing Asset, etc.)
Output → writes to Chatbot_Sa_SubcategoryPrompts table automatically.
