MATHEMATICAL ENGINE

Table Priority & Production Vitality Scoring Formulas

1. Production Priority Score Equation ($PriorityScore \in [0.01, 1.00]$)

Evaluates row count logarithmic volume, storage megabytes, and production status penalties:

S_volume = TotalRows == 0 ? 0.0 : min(1.0, log10(TotalRows + 1) / 5.0)
S_storage = min(1.0, DataSize_MB / 10.0)

Penalty = Backup_Table ? -0.60 : (Empty_Temp_Table ? -0.70 : (Master_Table ? +0.15 : 0.0))
BaseScore = (0.50 * S_volume) + (0.30 * S_storage) + Penalty + Bonus_active

PriorityScore = max(0.01, min(1.00, BaseScore))

2. 2-Step Semantic First RAG Retrieval & Prompt Slicing Architecture

Step 1: Pure Semantic Vector Retrieval ($k=5$) — Retrieves top 5 candidate tables strictly based on 100% vector similarity distance:

Vector Similarity (Sim) = max(0.0, 1.0 - (dist * 0.70))

Step 2: Prompt Slicing & Keyword Boost ($prompt\_k=2$) — Among top 5 semantic candidates, assigns query keyword match boosts (+0.15 per match) and selects top 2 schemas for LLM prompt:

Final Prompt Score = (0.75 * Sim) + (0.15 * PriorityScore) + min(KeywordBoost, 0.30)

-- Fetching Real-Time Row Counts & Data Sizes from SQL Server System Views
SELECT 
    t.name AS TableName,
    SUM(p.rows) AS TotalRows,
    CAST(ROUND((SUM(a.total_pages) * 8.0) / 1024.0, 2) AS FLOAT) AS DataSize_MB
FROM sys.tables t
INNER JOIN sys.indexes i ON t.object_id = i.object_id
INNER JOIN sys.partitions p ON i.object_id = p.object_id AND i.index_id = p.index_id
INNER JOIN sys.allocation_units a ON p.partition_id = a.container_id
WHERE i.index_id IN (0, 1) -- Heap or Clustered Index
GROUP BY t.name;
