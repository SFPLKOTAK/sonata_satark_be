5-Step Automated Setup for Any New Database

Step 1: Graph Scanning & Louvain Clustering

Database Graph Extraction & Domain Clustering

graph_taxonomy_scanner.py

Connects to the fresh database and extracts schema graphs (Foreign Keys, shared Primary Keys, and TF-IDF column similarity). Executes Louvain Community Detection to discover table communities, and invokes LLM to automatically name Categories (e.g., Domain 1: User Interaction...) and Subcategories. 

python -m db_scanner.graph_taxonomy_scanner
Step 2: LLM Schema Enrichment

Automated Schema Documentation & Data Dictionary

table_schema_enricher.py

Inspects INFORMATION_SCHEMA.COLUMNS for every table. Connects to LLM (Gemini/OpenAI) to generate detailed business purpose descriptions, column data dictionaries, explicit JOIN predicates, and populates dbo.Marklytix_TableDocumentation. 

python -m db_scanner.table_schema_enricher
Step 3: Taxonomy Reconciliation

Reconciliation & Specialized Domain Prompt Creation

reconciler_service.py

Reconciles staging records into production tables (Marklytix_Categories, Marklytix_Subcategories). Detects schema additions/modifications, constructs domain join predicates, and creates specialized domain system prompts in dbo.Marklytix_SubcategoryPrompts. 

python -m db_scanner.reconciler_service
Step 4: Vector Indexing & Priority Scoring

ChromaDB Vector Store Sync & Vitality Scoring

refresh_chroma_db.py

Queries database statistics (TotalRows, DataSize_MB from sys.partitions) to compute Production Priority Scores (0.01 - 1.00). Embeds enriched table documents, category vectors, and subcategory vectors into local persistent ChromaDB disk storage (chroma_db_storage). 

python -m db_scanner.refresh_chroma_db
Step 5: Launch Runtime Chatbot

Launch Django Channels WebSocket Engine

consumers.py

Launch the server. The multi-agent HierarchicalSearchConsumer is live and ready! Auditors and web users can now ask natural-language questions and receive real-time T-SQL queries, HTML data tables, and executive briefs. 

python manage.py runserver 0.0.0.0:8000

SCHEMA METADATA

Automated System Tables Created in SQL Database

dbo.Marklytix_TableDocumentation
Stores AI-generated business purposes, data dictionaries (ColumnMeanings), explicit join relationships (ConnectedTables), and Louvain cluster IDs.
dbo.Marklytix_SubcategoryPrompts
Contains specialized domain system prompts, domain T-SQL rules, and associated table lists for each subcategory.
dbo.Marklytix_Categories
Production category taxonomy mapping high-level operational domains (e.g. Credit Risk, Vault Control, Audit History).
dbo.Marklytix_Subcategories
Production subcategory taxonomy mapping targeted sub-domains with deduplicated search keywords.
dbo.Marklytix_Staging_Categories
Staging area for Graph Taxonomy Scanner to insert newly discovered candidate categories before reconciliation.
dbo.Marklytix_Staging_Subcategories
Staging area for newly discovered candidate subcategories prior to reconciliation.
